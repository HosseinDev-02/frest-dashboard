# Project Name
Genius Academy

## About
Every business needs a professional admin panel to manage itsactivities.
The First Panel, in addition to having a beautiful userinterface, also
consists of various charts, tables, calendars, etc. thatthe user can use
according to their needs. This panel has beendeveloped using React Js,
Tailwind Css and is fully responsive

## Features
- Different pages
- Different Charts
- Responsive
- Attractive user interface

## Tech Stack
- Tailwind CSS
- React

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/project-name.git
```

2. Navigate to the project directory

```bash
cd project-name
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

5. Open your browser and visit

```txt
http://localhost:5173
```
